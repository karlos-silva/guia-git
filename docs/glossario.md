# Glossário 📖

| Termo | Significado |
| --- | --- |
| **Branch** | Linha paralela de desenvolvimento. Tecnicamente, um ponteiro para um commit |
| **Clone** | Cópia de um repositório remoto no seu computador |
| **Commit** | Uma "foto" do projeto salva no histórico, com autor, data e mensagem |
| **Conflito** | Quando duas mudanças alteram as mesmas linhas e o Git precisa da sua decisão |
| **Detached HEAD** | Estado em que o HEAD aponta para um commit, não para uma branch |
| **Fast-forward** | Merge em que o Git só avança o ponteiro, sem criar commit de merge |
| **Fetch** | Baixar novidades do remoto sem aplicá-las |
| **Fork** | Cópia de um repositório de outra pessoa para a sua conta no GitHub |
| **Gist** | Trecho de código ou nota compartilhado no GitHub, sem repositório completo |
| **Hash** | Identificador único de um commit (ex.: `a1b2c3d`) |
| **HEAD** | Onde você está agora: normalmente a branch atual |
| **Hook** | Script que o Git roda automaticamente em certos eventos (antes do commit, antes do push) |
| **Issue** | Tarefa, bug ou ideia registrada no GitHub |
| **Merge** | Juntar o histórico de uma branch em outra |
| **Origin** | Nome padrão do remoto de onde você clonou |
| **Pull** | `fetch` + juntar as novidades na branch atual |
| **Pull request (PR)** | Pedido para juntar uma branch em outra, com revisão |
| **Push** | Enviar seus commits para o remoto |
| **Rebase** | Reaplicar commits em cima de outra base, deixando o histórico linear |
| **Reflog** | Registro de tudo que o HEAD fez. Rede de segurança para recuperar commits |
| **Release** | Versão oficial publicada no GitHub, baseada em uma tag |
| **Remoto** | Cópia do repositório em outro lugar (ex.: GitHub) |
| **Repositório** | Pasta do projeto com todo o histórico do Git (`.git`) |
| **Revert** | Commit que desfaz outro commit, sem apagar o histórico |
| **Squash** | Juntar vários commits em um só |
| **Stage (staging area)** | Área onde você prepara o que vai entrar no próximo commit |
| **Stash** | Gaveta para guardar mudanças temporariamente |
| **Tag** | Marcação fixa num commit, usada para versões (`v1.0.0`) |
| **Upstream** | O remoto original de um fork, ou a branch remota ligada à sua branch local |
| **Working directory** | A pasta com os arquivos do projeto, do jeito que estão agora |
